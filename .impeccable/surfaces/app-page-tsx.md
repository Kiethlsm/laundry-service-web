# Public laundry website

Mode: Persuade at /; Operate on booking, tracking and admin. User delegated all design decisions, including direct code implementation.

## Direction contract

THESIS: A small neighborhood laundry expressed through a blue enamel machine control panel. Choose a service, see its real starting price, book a pickup.
OWN-WORLD: Deep cobalt ink, pale blue enamel, warm white, restrained orange controls, Be Vietnam Pro typography. Circular selector in a rectangular panel; ruled lists elsewhere.
STORY: Identify the six services, understand estimated prices and four steps, book without an account, then look up using a code and phone.
FIRST VIEWPORT: Compact normal-flow welcome with booking, returning-customer lookup and real map/phone links beside the preserved CSS washer. Instructions and an explicit price-estimate qualification precede the washer controls. Then: a ruled six-service price index, a receive/agree/process/return story, and booking. Mobile follows the same reading order; full contact details remain in the footer without an adjacent duplicate strip.
FORM: Assigned #5, seed b3091e76. Grounded list: receipt, folded textile, neighborhood sign, garment care label, enamel wash controls, wardrobe inventory, domestic journal. Challengers judged for audience identification/product clarity: portrait plate competitive/declined; shelf inventory declined/competitive; data field declined/declined; oscilloscope declined/declined; quilt competitive/declined; indoor sun declined/declined. Retain caption precision, clear inventory, aligned numbers, definite states, material care and scale discipline respectively. Build uses the assigned controls, no borrowed motif.
SIGNATURE INTERACTION: User explicitly requested reverting the WebGL replacement because the prior design looked better. Preserve the CSS perspective washer, native-scroll rotation, selected-service marker and static reduced-motion pose. The 2026-10-25 layout removes the long sticky runway and calculates progress from scene/viewport height. No Three.js, canvas, autoplay, drag or pause toolbar.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
